# 🍕 Pizza Sales Analysis — Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Pizza Sales Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes pizza sales performance, customer ordering patterns, product performance, and sales trends to provide actionable business insights.

## 🎯 Business Objectives

The analysis aims to answer key business questions such as :

* What are the overall sales and order performance?
* Which pizza categories and products generate the most sales?
* What are the busiest days and hours?
* Which pizzas are the most and least popular?
* How does sales performance change over time?
* What insights can help improve business decisions?

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Analysis**

## 📈 Dashboard KPIs

The dashboard provides key performance indicators including:

* **Total Revenue**
* **Total Orders**
* **Total Pizzas Sold**
* **Average Order Value**
* **Average Pizzas per Order**

## 🔎 Key Analysis

The dashboard explores:

### 🍕 Product Performance

Analysis of pizza sales by category, type, and individual products.

### 📅 Time Analysis

Sales trends across different days, months, and hours to identify peak business periods.

### 🏆 Best & Worst Sellers

Identification of the highest- and lowest-performing pizzas based on sales and quantity.

### 👥 Customer Ordering Patterns

Analysis of order volume and the number of pizzas purchased per transaction.
